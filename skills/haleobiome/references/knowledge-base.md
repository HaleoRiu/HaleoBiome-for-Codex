> 用途：HaleoBiome 框架中 **Supervisor（监督者）** 的领域背景知识手册。
> 定位：独立、可公开、不含个人隐私与个人研究方向，随 HaleoBiome Skill 一并分发，供同行研究者共享。
> 原则：**知识地图 > 知识点堆砌**——提供「遇到 X 类问题该调用哪类知识、关注哪些关键概念、警惕哪些陷阱、锚定哪些关键文献/团队」，具体细节运行时按需检索。
> 结构：**核心（本文，通用）+ 扩展（领域专项，可挂载）**。个人研究方向（如冻土、碳循环）放扩展目录，不进入共享核心，便于随研究推进随时增删。

## 1. 生态学与微生物生态学基础

### 1.1 群落生态学核心概念

| 概念 | 定义 | Supervisor 需警惕的误用 |
|---|---|---|
| **α 多样性** | 群落**内部**多样性（样方/样本尺度） | 对测序深度敏感，尤其 Chao1/ACE 对稀有 OTU 敏感；深度不齐时结论失真 |
| **β 多样性** | 群落**之间**的组成差异（样方间/组间） | 度量选择（Bray-Curtis/Jaccard/UniFrac）会改变结论，应交叉验证 |
| **γ 多样性** | 区域总多样性（跨样方汇总） | 与 α/β 的尺度混淆是常见错误 |
| **群落构建** | 群落为何长这样：确定性（生态位/环境过滤）vs 随机（中性/扩散限制） | 相关 ≠ 因果；单一研究常无法区分二者 |

**核心认知**：
- **α/β/γ 是尺度概念**，必须在报告里说清在哪个尺度上讨论。
- **群落构建的确定性 vs 随机性之争**（Vellend 框架、null model 方法）是微生物生态学的中心议题之一；判断"环境驱动 vs 随机漂变"需要 null model（如 βNTI、Raup-Crick）而非只看相关性。

### 1.2 微生物生态学特有概念

- **"everything is everywhere, but the environment selects"**（Baas-Becking 假说）：微生物扩散能力强，但环境选择决定存续。适用于大尺度，小尺度上扩散限制可能更重要。
- **稀有生物圈（rare biosphere）**：微生物群落中大量低丰度类群。可能是有潜力的功能储备，也可能是测序噪声；分析时需权衡"过滤噪声"与"丢失信号"。
- **功能冗余（functional redundancy）**：不同类群可能执行相同功能。**分类学组成 ≠ 功能组成**——这是宏基因组/功能基因数据存在的根本理由。

### 1.3 微生物学基础（土壤微生物）

土壤微生物的主要门类及其典型生态角色（门水平相对丰度解读的基础）：

| 门 | 典型生态角色 |
|---|---|
| **Proteobacteria** | 代谢多样性最高，含大量营养型（copiotroph），富营养环境丰度高 |
| **Acidobacteriota** | 寡营养（oligotroph），酸性土壤、贫瘠环境丰度高 |
| **Actinobacteriota** | 降解复杂有机物（纤维素/几丁质），产抗生素，干旱耐受 |
| **Verrucomicrobiota** | 常见于土壤，部分参与甲烷氧化 |
| **Bacteroidota** | 降解高分子有机物，富营养、根际常见 |
| **Chloroflexota** | 寡营养，贫瘠/深层土壤常见 |
| **Firmicutes** | 产芽孢、抗逆，厌氧环境常见 |
| **Gemmatimonadota** | 干旱土壤常见，功能研究较少 |
| **Cyanobacteriota** | 光合固碳、固氮，生物土壤结皮（BSC）关键组分 |

**Supervisor 判断要点**：门水平的"丰度上升/下降"常被过度解读。营养型（copiotroph）vs 寡营养型（oligotroph）的框架（r/K 策略类比）比单纯罗列门丰度更有生态学解释力。**本表仅作检索与解释线索，不可把整个门视作固定的营养策略或功能类群**（同一门内策略差异很大）。

## 2. 微生物组方法学

### 2.1 扩增子测序（16S / 18S / ITS）

**关键方法选择与陷阱**：

| 主题 | 关键点 | 陷阱 |
|---|---|---|
| 引物选择 | 不同引物覆盖偏好不同（如 515F/806R vs 341F/806R） | 跨研究比较时引物不同不可直接合并 |
| OTU vs ASV | ASV（DADA2/deblur）分辨率更高、可跨研究比较；OTU（97% 聚类）传统 | 二者不可混用；ASV 可能过度拆分真实生物变异 |
| 抽平（rarefaction） | 深度不齐时抽平使样本可比 | **抽平丢信息、降功效**（McMurdie & Holmes 2014）；深度已齐时抽平是纯降信息的多余操作；Schloss 2024 认为深度不齐时抽平仍最稳健 |
| 组成性 | 16S 计数是**组成数据（compositional）**，只反映相对比例 | 不可把 read 数当绝对丰度做跨组"增减"解释 |

**组成数据分析（CoDA）共识**（Gloor et al. 2017）：
- 微生物组数据是组成的、非可选（non-optional）。
- CLR（中心对数比变换）是标准变换；零值处理是关键难点——**不应 rarefy 后再 CLR**（会制造伪零）。
- 差异丰度需处理组成性；ANCOM-BC、ALDEx2 等是候选而非统一默认。先核验具体实现的输入尺度、采样设计和重复测量支持；不能仅凭“组成数据方法”标签把相对丰度/CPM 传入要求原始计数的实现。

### 2.2 差异丰度分析（DA）方法学

| 方法 | 特点 | 陷阱 |
|---|---|---|
| **ANCOM-BC / ANCOM-BC2** | 组成数据 + 偏倚校正 | 需足够样本量；**并非「唯一最优」** |
| **ALDEx2** | CLR + 分布检验，FDR 控制好 | 需理解其 Monte-Carlo 抽样 |
| **DESeq2** | 负二项，原为 RNA-seq | 用于组成数据有 FDR 膨胀风险 |
| Wilcoxon on CLR + BH | 经典保守 | 功效较低 |

**方法选择原则（重要）**：Nearing et al. 2022 *Nat Commun* 的核心结论是**不同 DA 方法在同一数据集上结果差异巨大**，因此**不应把任何单一方法列为「最高推荐」**，而应：① 按设计选定主分析；② 按主要不确定性设计**预先定义的敏感性分析**；③ 报告一致与不一致之处——交集**仅作稳健性摘要，不自动替代完整主结果**。

> 注：敏感性分析可比较适用的方法、参数、过滤或模型设定；数量由研究问题、风险与资源决定，不设统一方法数下限。若存在重大不确定性却无法评估，须报告限制。

**硬性要求**：多重检验校正不可省，且须**预先说明校正的检验家族**，区分 **FPR / FWER（如 Holm）/ FDR（如 BH）**（不统称同一种假阳性率），分别记录原始 p 与校正后 p；先做 prevalence/丰度过滤减少检验数量。

### 2.3 多元统计方法

| 方法 | 用途 | 关键陷阱 |
|---|---|---|
| **PERMANOVA**（adonis2） | 检验组间组成差异 | **显著 ≠ 组间中心不同**——同时受中心位置与组内离散度影响，需检查离散度，并选择符合采样设计的诊断/检验（如适用时使用 `betadisper` / PERMDISP；Anderson 2006）；标准独立样本置换不适用于所有纵向/配对设计 |
| **PERMDISP**（betadisper） | 检验组内离散度齐性 | 若离散度也显著，PERMANOVA 显著可能只是方差异质性 |
| **dbRDA/CCA/RDA** | 约束排序，量化环境解释方差 | 报告 **adjusted R²**（**可为负**，不受 0–1 限制）；**VIF>10 提示严重共线**，处理方式依研究问题定（删/合并/降维/保留并仅作整体与排序解释、变量级用 margin 检验），**不机械删除**；共线因子的独立贡献不可分离 |
| **NMDS** | 非度量排序，保序更稳健 | 报告 stress（<0.2 可接受，<0.1 优） |
| **PCoA** | 主坐标分析 | Bray-Curtis **非欧几里得**，原始距离谱**可能有负特征值**；`capscale(dist~1)` **默认 `add=FALSE`**，在排序中**忽略负特征值对应的虚轴**（**并非** Cailliez 加常数校正；`$CA$eig` 因此全为非负）；**诊断负特征值须在原始谱上做**（`wcmdscale(dist, eig=TRUE)`，或读 `capscale$CA$imaginary.rank/chi`），并说明轴解释率的分母（正特征值之和） |

**输入方向**：接收**群落矩阵**的 vegan 函数要求**样本为行**（OTU×样本时须 `t()`）；**已计算好的距离对象**只需校验标签/维度/顺序，不再笼统要求转置。

### 2.4 关键团队锚点

- **周集中（Jizhong Zhou，俄克拉荷马大学）**：GeoChip 功能基因芯片、群落构建理论、随机森林在微生物生态的应用、环境微生物组学方法学。其团队工作覆盖"功能基因 > 分类学"的核心主张。
- **刘永鑫（Yong-Xin Liu，中国农科院）**：微生物组数据挖掘方法学、扩增子分析标准化流程、R 包与教程体系（EasyAmplicon 等），中文社区扩增子分析的事实标准之一。
- **Rob Knight / Curtis Huttenhower**：微生物组统计与工具生态的奠基者（QIIME、QIIME2、LEfSe 等）。

### 2.5 功能解释的层级（避免过度外推）

| 证据类型 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 扩增子（16S/ITS）推测功能（PICRUSt / FAPROTAX 等） | 潜在功能倾向 | 实际表达/活性 |
| 宏基因组功能基因 | 功能**潜能** | 是否被表达 |
| 宏转录组 / 蛋白 | 表达/翻译层面的活性 | 实际过程速率 |
| 实测过程速率 / 通量（培养、同位素等） | 过程确实发生及其量级 | 归因于特定类群（需额外证据） |

**铁律**：**基因丰度不能直接推出生态过程增强**；跨层级外推必须显式说明证据强度。

## 3. 批判性思维（贯穿性元能力）

> 这是 Supervisor 的**元能力**，贯穿所有审查，而非单独的"知识点"。

### 3.1 核心追问清单（对每个核心断言）

1. **凭什么？** —— 证据链是否闭合？从数据到结论的每一步推理是否有据？
2. **相关性 ≠ 因果** —— 分析说"X 导致 Y"，证据实际上只支持"X 与 Y 相关"吗？
3. **替代解释是什么？** —— 同样的数据还能怎么解读？哪个解释证据更强？
4. **外推的边界在哪？** —— 基于子集的 if 外推，代表性够吗？
5. **外部一致性** —— 与其他环境/系统的同类研究一致吗？

### 3.2 常见系统性错误

1. **论文翻译 ≠ 论文分析**：按论文自己的叙事框架复述，而非质疑底层逻辑。
2. **相关性当因果**：发现"功能基因附近有 MGE"就声称"MGE 影响功能"，忽略了这可能是自私元件的自我扩增。
3. **if 外推当结论**：基于小比例可分析子集的推断被当成总体结论。
4. **替代解释缺失**：没有追问"这数据还能怎么解读"。
5. **方法论混用**：把跨多个时间尺度的指标混为"整合证据"。
6. **局限性仅作装饰**：局限性放在结尾 checklist，而非贯穿全文质疑每个断言。

### 3.3 Supervisor 审查时的应用

- 对 **Planner 的方法选择**：这个方法在这个数据/样本量下站得住吗？有没有更稳健的替代？
- 对 **Analyzer 的结论**：这个结论是"证据实际支持的"，还是"看起来合理但证据不足的"？
- 对 **数据事实**：分组、环境方向、库大小等，必须**代码实测交叉验证**，不得靠记忆/先验推断（防幻觉第一原则）。

### 3.4 方法规则的使用原则（元规则）

本知识库的方法条目是**带条件的启发式**，不是铁律：

- 每条规则应尽可能附**适用场景、主要限制、文献/官方文档来源与核验日期**；
- **不要把某次项目中的具体处理方式，直接提升为所有微生物组数据的通用铁律**；
- 遇到规则间冲突或数据不满足前提时，**记录异常与替代解释**，由 Supervisor 判断，而非机械套用。

## 扩展机制（如何自定义）

本知识库采用「**核心 + 扩展**」结构，便于研究者按自己方向增删领域知识，而无需改动共享核心。

- **核心**（本文件）：通用生态学/方法学/批判性思维，对所有生信下游分析适用。
- **扩展**：个人研究方向（如冻土、碳循环、肠道微生物、海洋微生物等），以独立 `.md` 文件放入用户指定的领域知识目录，运行时按需挂载。
- **扩展文件可包含**：
  - 领域核心概念（表格：概念 / 定义 / 陷阱）
  - 关键方法选择与陷阱
  - 关键团队/文献锚点
  - 批判性追问清单（本领域专属）

> 提交共享版时，只提交核心知识库；个人扩展留在本地或私有仓库。
